# Глоссарий

Канонические термины. Любой system-файл использует ровно эти формы при первом упоминании.

| Термин | Значение |
|---|---|
| **Арена** | игровое поле фиксированной раскладки с адаптивным одноэкранным обзором. См. [arena](systems/arena.md). |
| **Сетка территории** | CPU-дискретизация арены на квадратные клетки (`ArenaGrid`). Состояния клетки: `Empty` / `Territory` / `Line` / `Obstacle`. |
| **Grid resolution** | сторона квадратной сетки в клетках, `ArenaConfig.GridResolution`. Целевой дефолт после scale-up — 500 (минимум приёмки 256). См. [perf-budget](meta/perf-budget.md). |
| **Adaptive zoom-out** | поведение камеры: статична на мелкой петле, отъезжает при крупной. Сохраняет «обзор как на одном экране» на 100×100 карте. См. pillar 5 в [pillars](pillars.md). |
| **Tier 0 / Tier 1** | архитектурные уровни производительности. Tier 0 — текущий MVP-потолок (≤200 врагов, manager-driven loop). Tier 1 — ≥500–1000 врагов, batched-блит и GPU-эрозия; пост-scale-up задача. См. [enemies](systems/enemies.md), [perf-budget](meta/perf-budget.md). |
| **Маска пола** | GPU-рендертекстура арены. Зеркалит сетку, но с большей плотностью пикселей (см. `ArenaConfig.TexelsPerWorldUnit`). |
| **Краска** | основной ресурс. Тратится на заливку клеток при замыкании петли. Не тратится на рисование активного следа. |
| **Территория** | закрашенные клетки игрока. Барьер для врагов, источник пассивного урона по ним. См. [territory](systems/territory.md). |
| **Активный след** | непрерывная линия по реальной траектории игрока, лежит на отдельном слое. Клетки в состоянии `Line`. |
| **Спящая фаза трейла** | состояние, когда игрок движется по своей `Territory` — рисунок не оставляется. |
| **Активная фаза трейла** | состояние, когда игрок шагнул в `Empty` — каждая пройденная клетка становится `Line`. |
| **Замыкание (петли)** | касание активным следом своей территории или края арены; запускает поиск охваченной области и заливку. |
| **Заливка** | прогрессивная BFS-волна по охваченным клеткам (`FloodFillAnimator`), превращающая их в `Territory` за счёт расхода краски. |
| **Эрозия** | выедание `Territory → Empty` врагом, стоящим на её границе. См. [enemies](systems/enemies.md). |
| **Масло** | редкий ресурс точечного действия против толп и громил. См. [oil](systems/oil.md). |
| **База** | стартовая закрашенная зона в центре, источник пассивной регенерации краски. |
| **Шахта** | стационарный источник ресурса. В `Territory` — непрерывная выдача в банк; в `Empty` — копит сток до включения в петлю. |
| **Бутылёк** | одноразовый пикап ресурса. См. [resources](systems/resources.md). |
| **Банк** | счётчик ресурса с лимитом (`PaintBank` для краски, `OilBank` будущий). |
| **Волна** | расписанное появление группы врагов из заданного сектора арены. См. [waves](systems/waves.md). |
| **Телеграф** | визуальное предупреждение игрока о направлении и времени волны (3–5 сек подсветки сектора). |
| **Громила** | редкий тяжёлый враг, игнорирует урон от территории. Контр — только масло. |
