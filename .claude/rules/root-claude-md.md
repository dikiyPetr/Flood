# Корневой CLAUDE.md

Файл хранится **пустым**. Не добавлять `@`-импорты, принципы или правила.

Подгрузка контекста — динамическая:

- **Правила** — `.claude/rules/*.md` с `paths:` frontmatter. Авто-подгружаются по scope, в котором идёт работа.
- **Скиллы** — `.claude/skills/c-{name}/SKILL.md`. Триггерятся через `description` (см. `c-prompt`, `c-shader`) или явный `/c-{name}`. Скилл может `@`-импортить нужные правила в свой сценарий.
- **Модульные правила** — `Assets/Modules/<Module>/CLAUDE.md`, авто-load в поддереве.

Если хочется «общий принцип на весь проект» — это сигнал писать новое `paths`-правило, не возвращать содержимое в корневой CLAUDE.md.
